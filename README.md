# HS300 理想约束账本

项目二：从项目一方案三动量公式拎出的净多头账本，允许做多、做空、弱市降仓。研究界面，不是交易系统。

和项目一不是同一件事。项目一 [aris4u/hs300-strategy](https://github.com/aris4u/hs300-strategy) 是大A指数增强：70% 跟踪沪深300 + 30% 卫星，**不做空**，无信号时 100% 指数。本仓库只读项目一已经下好的日K，不改项目一文件，也不能和项目一那大约 4–6 个百分点超额直接比。

目标：**无未来函数、T+1 开盘成交、规则事先固定、不对 2024-09 报告窗口搜参**。不优化回测收益。

## 执行口径

- T 日收盘生成信号（20 日价格动量，跳过最近 1 日）。
- T+1 日开盘成交。约每 21 个交易日换仓。
- **禁止**用 T 日收盘价作为成交价。
- 成本：佣金 3bp + 滑点 5bp + 印花税 10bp（卖出）。空头另计年化 5% 融券费。
- 实现：`hs300_ls/book.py`；公式在 `hs300_ls/formula.py`。不跑通达信状态机。

## 仓位

总敞口约 100%：做多动量最高 5 只合计约 70%，做空最低 5 只合计约 30%。净敞口约 +40%。沪深300收盘低于 60 日均线时整体 ×50%，不空仓。

这是理想约束，不是大A可直接执行结果：A 股不能随便做空这些票，融券费率也不是统一 5%。当前成分名单，有幸存者偏差。

参数冻结在 `hs300_ls/config.py`。要改规则只能在 Train 讨论；对着报告窗口调仓位或动量窗口，不算。

## 仓位结构对照

同一套 20 日动量、T+1 开盘、佣金/滑点/印花税/融券。只改仓位结构。不是在报告窗口上搜参。示意图蓝点仍是产品默认 70/30 半仓。

| 仓位 | 相对超额 | 累计差 | 报告回撤 | Train 净值 | Train 回撤 | 报告净值 | 夏普 |
|---|---|---|---|---|---|---|---|
| **当前：70/30 弱市半仓** | +60.67% | +88.09% | −15.72% | +31.92% | −48.83% | +133.30% | 1.69 |
| 70/30 弱市 75 折 | +78.92% | +114.60% | −17.57% | +23.33% | −51.91% | +159.81% | 1.80 |
| 85/15 弱市半仓 | +107.99% | +156.81% | −20.62% | +131.13% | −56.73% | +202.02% | 1.78 |
| 只做多、弱市半仓 | +165.28% | +240.01% | −25.66% | +279.22% | −64.43% | +285.21% | 1.82 |
| 只做多、满仓不降 | +319.53% | +463.99% | −30.51% | +327.17% | −68.43% | +509.20% | 2.15 |

满仓只做多能到约 300% 相对超额，那是旧方案三量级，回撤不再接近指数。若回撤要和指数差不多（约 −16%），相对超额大约就停在 +61%。界面「超额与回撤」页可点一行，回测和目标仓位跟着换。

## 目标仓位

界面「目标仓位」页给出最近一次换仓锁定的多头 5 只 / 空头 5 只、权重、信号日和下一开盘成交日。用来核对公式，不是当日买卖建议。

## 下一步与未做的事

这是当前证据还盖不住的地方，不是「做成了就会赚钱」的路线图。

**数据与基准**
- 成分改成 point-in-time：现在用的是当前沪深300名单，有幸存者偏差。
- 价格只读项目一缓存，本仓库不自己拉日K。项目一没准备好 `universe_v1.pkl`，这里跑不起来。
- 指数口径是项目一那份前复权日K上的沪深300，不要和全收益指数混比。
- 空头是账本假设（印花税 + 年化 5% 融券），不是可借券、可成交的实盘。

**研究**
- Train 跑不赢指数、回撤约 −49%。把报告窗口 +133% 写成长期能力，不算。
- 2026 有过很肥的月份。分段表要留着，避免只报赢的一段。
- 对照表说明超额和回撤是同一方向。想再加超额，先接受更深回撤，而不是再搜一套窗口。

**产品与工程**
- 目标仓位是最近一次规则输出，不是选股建议中心。
- GitHub 克隆需要本机 Python，仓库里不带 runtime，也不带 `output/` 回测结果。
- 界面默认 http://127.0.0.1:8766/。项目一仍在 8765。

**明确不做**
- 不把报告窗口结果拿去调参。
- 不把满仓只做多的约 300% 相对超额说成当前产品。
- 不把本账本超额和项目一的 4–6 个百分点直接比。
- 不把空头写成大A可执行做空。
- 不把目标仓位页写成买卖指令。

## 从 GitHub 运行（Windows）

克隆下来需要本机已装 Python 3.13，并且旁边有项目一的价格缓存。

```text
git clone https://github.com/aris4u/hs300-strategy.git vibe2
git clone https://github.com/aris4u/hs300-ls.git
cd hs300-ls
python -m pip install -r requirements.txt
```

先在项目一生成 `vibe2/output/enhance_opt/universe_v1.pkl`（见项目一 README）。两个目录默认是同级；否则设置环境变量 `VIBE2_ROOT` 指向项目一目录。

```text
python run_backtest.py
python app.py
```

或双击 `HS300-LS.cmd`。界面：http://127.0.0.1:8766/

规则提示，不是投资建议。

## 命令

```text
python run_backtest.py          # 账本 + 仓位对照（T+1 开盘，含成本）
python app.py                   # UI，默认 8766
```

输出：`output/book_*`、`output/frontier.*`、`output/variants/`。参数冻结于 `hs300_ls/config.py`。任何改动必须记录旧值/新值、原因，且只能在 Train 讨论，报告窗口冻结。
