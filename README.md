# HS300 理想约束账本

第二个项目：从指数增强里的动量公式拎出的净多头账本。允许做多、做空；弱市可以对照空仓。研究界面，不是交易系统。

原来的指数增强在 [aris4u/hs300-strategy](https://github.com/aris4u/hs300-strategy)：70% 跟踪沪深300 + 30% 卫星，**不做空**，无信号时 100% 指数，严格按大A规则。本仓库自己用 BaoStock 拉日K。两边超额不能直接比。

目标：**无未来函数、T+1 开盘成交、不对 2024-09 报告窗口搜参**。不优化回测收益。

## 执行口径

- T 日收盘生成信号（20 日价格动量，跳过最近 1 日）。
- T+1 日开盘成交。约每 21 个交易日换仓。
- **禁止**用 T 日收盘价作为成交价。
- 成本：佣金 3bp + 滑点 5bp + 印花税 10bp（卖出）。空头另计年化 5% 融券费。
- 实现：`hs300_ls/book.py`；公式在 `hs300_ls/formula.py`。

## 仓位

当前产品：总敞口约 100%。做多动量最高 5 只合计约 70%，做空最低 5 只合计约 30%。净敞口约 +40%。沪深300收盘低于 60 日均线时整体 ×50%，**不空仓**。

「空仓」对照：同一套 70/30、85/15、只做多，弱市改成 0。报告窗口超额大约腰斩，回撤没有变浅，所以产品仍用半仓。票不够 3 只时，所有档位都会把权重打成 0。

这是理想约束，不是大A可直接执行结果：A 股不能随便做空这些票，融券费率也不是统一 5%。当前成分名单有幸存者偏差。

参数冻结在 `hs300_ls/config.py`。要改规则只能在 Train 讨论；对着报告窗口调仓位或动量窗口，不算。

界面「超额与回撤」点一行，回测和目标仓位跟着换。

## 目标仓位

「目标仓位」页是最近一次换仓锁定的名单，用来核对公式，不是当日买卖建议。最近一次信号日若正好弱市空仓，账本权重全是 0；表里会另列「若未空仓」的对照名单和权重。

## 界面

打开 `HS300-LS.cmd` 或 `python app.py`，默认 http://127.0.0.1:8766/ 。黑窗口不要关，后台按 21 个交易日换仓检查：收盘后才拉日K，盘中不写未收盘K。顶栏显示下次更新日期；页脚是北京时间和通达信连接状态。

## 下一步与未做的事

**数据与基准**
- 现在用的是当前沪深300名单，有幸存者偏差。
- 日K 用 BaoStock 前复权，缓存在本仓库 `data/`。指数用不复权口径，不要和全收益沪深300混比。

**研究**
- 2026 有过很肥的月份。分段表要留着，避免只报赢的一段。
- 对照表说明超额和回撤是同一方向。弱市空仓在报告窗口并不更好。想再加超额，先接受更深回撤，而不是再搜一套窗口。

**产品与工程**
- 目标仓位是最近一次规则输出，不是选股建议中心。
- GitHub 克隆需要本机 Python，仓库里不带 runtime，也不带 `output/` 和 `data/`。

## 从 GitHub 运行（Windows）

克隆下来需要本机已装 Python 3.13。第一次会自己拉沪深300成分日K（BaoStock，无需密钥），大约十几分钟。

```text
git clone https://github.com/aris4u/hs300-ls.git
cd hs300-ls
python -m pip install -r requirements.txt
python run_download.py
python run_backtest.py
python app.py
```

或双击 `HS300-LS.cmd`。界面：http://127.0.0.1:8766/

本仓库不改指数增强仓库的文件。若本机已经有 `universe_v1.pkl`，自行下载失败时会拿它当后备。

规则提示，不是投资建议。

## 命令

```text
python run_download.py          # 拉成分 + 日K 到 data/（第一次约十几分钟）
python run_backtest.py          # 账本 + 仓位对照（T+1 开盘，含成本）
python run_backtest.py --refresh
python run_update.py --once     # 检查一次；开着界面也会自己跑
python run_update.py --install  # 可选：写入每日 15:25 计划任务
python app.py                   # UI，默认 8766
```

输出在本地 `output/`，不进 Git。参数冻结于 `hs300_ls/config.py`。任何改动必须记录旧值/新值、原因，且只能在 Train 讨论，报告窗口冻结。
